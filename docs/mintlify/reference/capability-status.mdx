This page is the source of truth for which FERAL capabilities are usable today, which need operator configuration to come online, and which are still in active development. It is hand-maintained and verified against the shipped code at each release (there is no code generator for this file yet); the version stamp is the published wheel on PyPI.

**Version:** v2026.6.29 — `pip install feral-ai==2026.6.29`

| Legend | Meaning |
|--------|---------|
| **Available** | Shipped and usable; tested in CI; ready out of the box. |
| **Available — operator setup** | Shipped and tested, but requires you to provide credentials, hardware, or external services. |
| **In development** | Code is being actively wired; ships in a follow-up release. See the linked guide for current state. |

## Brain

| Capability | Status | Notes |
|------------|--------|-------|
| LLM orchestration (10 runtime providers) | Available | OpenAI, Anthropic, Google Gemini, Groq, DeepSeek, OpenRouter, Moonshot (Kimi), Qwen, plus local Ollama and LM Studio. Per-call routing with automatic failover. |
| Together / Fireworks / Amazon Bedrock | In development | Exposed in the provider catalogue and Settings UI, but they do not yet share the OpenAI-compatible runtime chat adapter the providers above use (Bedrock runs a separate `converse` path). Reconciling this catalog↔runtime split is in progress. |
| Multi-key per provider | Available | Add multiple labeled keys per provider in **Settings → Providers**; switch the active key without restarting. |
| Skill registry + tool dispatch | Available | 157 manifest endpoints, contract-tested. See [Skills](/guides/skills). |
| MCP client | Available | Connects to external MCP servers (HTTP, stdio, SSE). |
| MCP server | Available | Exposes FERAL tools at `/mcp` for other agents. |
| Autonomy modes (strict / hybrid / loose) | Available | Enforced on every tool dispatch path. See [Autonomy](/guides/autonomy). |
| Approval queue | Available | Blocks dangerous operations until you confirm in the WebUI or CLI. |
| Cost budget + per-call caps | Available | Per-subsystem and global caps (unlimited until you set one). Both the chat path and the ScreenLoop path emit a budget banner when a configured cap is hit. |

## Memory

| Capability | Status | Notes |
|------------|--------|-------|
| Working memory (per session) | Available | Scoped to session lifetime. |
| Episodic memory (SQLite + FTS5 + vector) | Available | Hybrid full-text + vector search with MMR re-ranking. |
| Knowledge graph | Available | Entities and relations queryable via API and CLI. |
| Timeline (`/api/timeline`) | Available | Reads episodes for a unified life view; degrades gracefully under load. |
| Wiki compilation | Available | Ingest repositories, PDFs, plain text; browse and search. |
| HLC-based peer sync | Available — operator setup | Requires at least two paired FERAL nodes on the same network or remote tunnel. The `/sync` handshake authenticates with a constant-time passphrase comparison and a per-peer failed-attempt lockout. |
| Vault (credential) encryption at rest | Available | Secrets live in a ChaCha20-Poly1305 vault whose master key is derived from your OS keychain. |
| Memory-database encryption at rest | Available — operator setup | `feral memory encrypt` encrypts `~/.feral/memory.db` with ChaCha20-Poly1305 (subkey via HKDF-SHA256 from the vault master). It is a one-shot, brain-stopped operation (`feral stop` → `feral memory encrypt` → `feral start`); the DB is decrypted to a runtime file on boot. |
| Always-live memory encryption + key rotation | In development | Encrypting the DB while it is in use (rather than decrypting to a plaintext runtime file) and `feral memory encrypt --rotate` are not yet shipped. |

| Gemini Live | Available — operator setup | Bidirectional audio streaming. Needs a Google key. |

| Provider catalogue (`/api/voice/providers`) | Available | Lists all 8 providers with live probe status. |

| Wake word | Available — operator setup | `openwakeword` integration; quality varies by environment. |
| Realtime → chained automatic fallback on quota | Available — operator setup | An OpenAI Realtime quota / 1013-class error auto-morphs the live session to the chained Deepgram + ElevenLabs pipeline (`audio.fallback_mode: chained`, the default) and emits a `voice_status` degraded banner. Needs Deepgram + ElevenLabs keys in the vault. |

## Hardware

| Capability | Status | Notes |
|------------|--------|-------|
| HUP 1.3.0 (Hardware Unified Protocol) | Available | Unified across brain, SDKs, and daemon manifests. CI-gated. |
| Generic self-describing hardware hub | Available | `actions[]` → `DeviceManifest` → `GenericHardwareSkill` LLM tools; per-manifest permission tiers and `rate_limit_per_minute` are enforced on dispatch; honesty loop via `verify` contract. Kill switch: `FERAL_GENERIC_HARDWARE_SKILLS`. |
| Robot motion fail-safe (host-side) | Available | A host-side dead-man watchdog issues a best-effort `halt` when the brain shuts down or the serial / mesh link drops, so a continuous-motion command cannot run away. |
| Brain-local device discovery | Available | Config-driven `DEVICE_DISCOVERY_SPECS`; CuteBot via `FERAL_CUTEBOT_PATH`. |
| Phone-bridged BLE peripherals | Available | `BridgedPeripheralAdapter` + `peripheral_bridge_register`. |
| Hardware fleet API | Available | `GET /api/hardware/fleet` — manifests, safety tiers, last verification state, mesh snapshot. |
| Device registry + pairing | Available | QR pair / WebUI pair / CLI `feral devices`. |
| Hardware mesh | Available | Request/response correlation across nodes. |
| Home Assistant bridge | Available — operator setup | Requires a running HA instance and long-lived access token. |
| Smart-glasses ingest (camera node) | Available — operator setup | Phone-camera node streams `glasses_frame`. |
| Smart-glasses BLE adapter (W610 / QCSDK) | In development | Hardware-specific adapter wiring; phone-camera path is the supported alternative today. |
| Per-device capability grants (`node_ack`) | In development | The HUP `node_ack` frame carries `granted_capabilities` / `denied_capabilities`, but the brain currently grants every capability a node advertises and denies none — user-gated per-capability approval is not yet enforced. |

## Security

| Capability | Status | Notes |
|------------|--------|-------|
| BlindVault (encrypted secrets) | Available | ChaCha20-Poly1305 AEAD; master key derived from your OS keychain. |
| Audit log (fail-loud) | Available | Append-only; tampering surfaces in `feral doctor`. |
| Sandbox policy module | Available | YAML-loaded; enforced for skill execution, computer use, and the `daemon://local/shell` path (allowlisted binaries + shell-metacharacter rejection via `validate_shell_command`). |
| Marketplace / skill install hardening | Available | Archive members are validated **before** extraction (zip-slip / path-traversal entries rejected), and remote install URLs are SSRF-guarded (private, loopback, and link-local address ranges blocked). |
| Approval bypass tests | Available | CI-gated; ships in every release. |
| Local-bypass for paired LAN | Available | Off by default; opt-in per device. |

### How this page stays honest

Every row is verified against shipped code at the version stamped above. If you find a row that doesn't match what your installation actually does, [open an issue](https://github.com/FERAL-AI/FERAL-AI/issues) — that's a bug, not a documentation oversight.

For the runtime version of this matrix, run:

```bash
feral doctor
```

For per-provider availability and credentials probe, run:

```bash
feral key list
feral voice providers
```
