## Scope and definitions

The source of truth is [App.jsx](../feral-client-v2/src/App.jsx), the actual page/component implementations, and [Settings.jsx](../feral-client-v2/src/pages/Settings.jsx). There are **44 explicit route patterns** in App.jsx, including nested phone paths, aliases, and the wildcard, plus the phone index redirect and a pathless shell wrapper. Settings has **16 actual sections**. Source-defined navigation alone is insufficient evidence of working feature parity; read/write actions and safeguards also need native equivalents.

- **Partial**: some real native UI and API paths exist, with the omissions named below. It does not mean the remaining capability is usable indirectly through the native screen.
- **Missing**: no native screen/control implements the capability. Its backend and existing web UI may still exist; retaining Python resources does not expose the feature in SwiftUI.
- **URL mapping absent**: native does not implement that web route/bookmark/deep-link behavior. The web alias remains intact.
- **R** denotes a read, usually GET; **W** denotes a write/action with the concrete HTTP method or socket action. Parameterized API paths below abbreviate URL-encoded IDs and query parameters.

Read every row as four distinct evidence fields: **implemented source**, **fixture coverage**, **actual acceptance**, and **remaining code**. A partial status does not mean the backend or native screen must be rewritten. The 44 web route patterns include aliases and phone routes, not 44 missing Mac features. The [execution plan](../docs/roadmap/theora-personal-agent/EXECUTION_PLAN.md) assigns concrete remaining work and preserves the supported single-user runtime while new integrations are added.

Native feature milestones are tracked in [MIGRATION_PLAN.md](MIGRATION_PLAN.md). Native sources: [NativeHealthFeature.swift](NativeHealthFeature.swift), [NativeMemoryFeature.swift](NativeMemoryFeature.swift), [NativeOversightFeature.swift](NativeOversightFeature.swift), [NativeConversationFeature.swift](NativeConversationFeature.swift), [NativeProvidersFeature.swift](NativeProvidersFeature.swift), [NativeConfigurationFeature.swift](NativeConfigurationFeature.swift), [NativeVoiceFeature.swift](NativeVoiceFeature.swift), [NativeSecurityFeature.swift](NativeSecurityFeature.swift), [NativeOperationsFeature.swift](NativeOperationsFeature.swift), [NativeConnectionsFeature.swift](NativeConnectionsFeature.swift), [NativeViews.swift](NativeViews.swift), [APIModel.swift](APIModel.swift), [NativeApp.swift](NativeApp.swift), [BrainRuntime.swift](BrainRuntime.swift).
