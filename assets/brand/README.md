# FERAL brand mark

`feral-logo-original.png` is the exact image supplied by Mahmoud on September 30, 2026. Keep it separate from the selectable companion/avatar. Its original geometry and black-on-white treatment are preserved.

`scripts/prepare_brand_assets.py` derives size/format variants for the macOS app icon, native interface, retained desktop shell and web manifest. It needs Pillow and Apple's `iconutil`; run with a Python installation containing Pillow. Generated assets do not establish permission to replace an installed app or publish a release.

The iOS agent can use this canonical source for its own asset catalogue. No iOS source was changed.
